1. ข้อมูลภาพรวมและสเปกเครื่องเป้าหมาย (SYSTEM OVERVIEW & TARGET SPEC)
--------------------------------------------------------------------------------
- โปรเจกต์: Desktop App ถอดเสียงการประชุม (Speech-to-Text) แบบ Modern Dark Mode
- ฮาร์ดแวร์เป้าหมาย: การ์ดจอ NVIDIA GeForce GTX 1660 Super (VRAM 6GB) บน Windows
- เทคโนโลยีหลัก:
  * GUI: CustomTkinter (ฟอนต์ภาษาไทย "Leelawadee UI" คมชัด สบายตา ขนาด 14)
  * AI Engine: faster-whisper (CTranslate2) 
  * Audio Handling: PyAV (av) ในตัว รองรับ .mp3, .wav, .m4a, .mp4, .aac, .flac ฯลฯ
  * Threading: Python threading.Thread (daemon) + queue.Queue แยกการทำงาน 100% 
    หน้าต่าง GUI ไม่ค้าง (Zero-Freeze) แม้ประมวลผลไฟล์เสียงยาว 5 ชั่วโมงขึ้นไป

--------------------------------------------------------------------------------
2. ฟีเจอร์ที่พัฒนาเสร็จสมบูรณ์แล้วในโปรแกรม (COMPLETED FEATURES)
--------------------------------------------------------------------------------
1. การเลือกไฟล์:
   - ปุ่มเลือกไฟล์เสียง/วิดีโอ แสดงชื่อไฟล์ ขนาดไฟล์ (MB/GB) และความยาวเสียง (HH:MM:SS)
2. การตั้งค่าโมเดลและอุปกรณ์:
   - Model Dropdown: "tiny", "base", "small" (ค่าเริ่มต้น: "small" แม่นยำสูงสำหรับภาษาไทย), "medium"
   - Device Dropdown: "CUDA (GPU)" และ "CPU"
   - Language Dropdown: "ไทย (Thai)" (ค่าเริ่มต้น), "Auto Detect", "อังกฤษ (English)"
3. ⚡ โหมดความเร็วสูง (Turbo Mode):
   - มีสวิตช์เปิด/ปิดบนหน้าจอ
   - เมื่อเปิด: ปรับเป็น Greedy Search (beam_size=1) และรัน int8_float16 บนชิป Turing ของ 1660S
   - ลดเวลาประมวลผลลง 2–3 เท่า (ไฟล์ 5 ชม. จาก ~45 นาที เหลือเพียง ~15-20 นาที) กิน VRAM เพียง ~1.2 GB
4. ⏱️ กำหนดช่วงเวลาที่ต้องการถอด (Custom Time Range):
   - ช่องกรอกเวลาเริ่มต้นและสิ้นสุด เช่น 01:00:00 ถึง 02:30:00 (ใช้ clip_timestamps ของ Whisper)
   - กระโดดข้ามไปถอดเฉพาะช่วงที่เลือกทันที ไม่ต้องรอทั้งไฟล์
   - คง Timestamp ตามเวลาจริงของคลิป และมีปุ่ม "ทั้งไฟล์" เพื่อรีเซ็ตกลับอัตโนมัติ
5. แถบแสดงความคืบหน้า (Progress Bar & ETA):
   - Progress bar (0 - 100%), เวลาที่ใช้ไป (Elapsed), เวลาที่เหลือโดยประมาณ (ETA), ตำแหน่งเสียง
6. กล่องข้อความสด (Real-time Transcript Box):
   - ข้อความพร้อมเวลา [HH:MM:SS] ทยอยขึ้นสดทีละประโยค พร้อม Auto-scroll
   - ปุ่มคัดลอกข้อความ (Copy to Clipboard) และปุ่มล้างหน้าจอ
7. การบันทึกไฟล์ (Real-time File Append):
   - บันทึกลงไฟล์ transcript.txt แบบ flush() ทันทีทุกประโยค ป้องกันข้อมูลสูญหาย
   - ปุ่ม "บันทึกเป็น .txt" สำหรับ Export ไปที่อื่น และปุ่ม "เปิดโฟลเดอร์ผลลัพธ์"
8. ระบบตรวจสอบ GPU และ Auto-Fallback:
   - ป้ายสถานะฮาร์ดแวร์ด้านบนขวาจะตรวจเช็ก Driver และ CUDA ทันทีเมื่อเปิดโปรแกรม
   - หาก Driver เก่าเกินไป ป้ายจะขึ้นสีส้มและสลับไปใช้ CPU ให้อัตโนมัติ (คลิกดูวิธีแก้ได้)
   - หากรันบน GPU แล้วมีปัญหา จะมีหน้าต่างถามเพื่อสลับไป CPU และรันต่อทันที ไม่เด้งหลุด

[สาเหตุ]:
1. Driver การ์ดจอ NVIDIA ที่บ้านเป็นเวอร์ชันเก่า (เก่ากว่า v528.xx):
   faster-whisper ตัวปัจจุบันทำงานบน CUDA 12 ซึ่งต้องการไดรเวอร์ NVIDIA v528 ขึ้นไป 
   หากเครื่องที่บ้านใช้ไดรเวอร์เก่าที่ติดมากับ Windows (เช่น v456 หรือ v472) ระบบจะเกิดข้อผิดพลาด:
   "CUDA driver version is insufficient for CUDA runtime version"
2. หรือเครื่องที่บ้านเพิ่งก๊อปปี้โฟลเดอร์ไป ยังไม่ได้รันไฟล์ install.bat
