# ระบบถอดเสียงการประชุม AI (Meeting Transcriber Desktop App)

โปรแกรม Desktop สำหรับถอดเสียงการประชุมและไฟล์บันทึกเสียง/วิดีโอ (Speech-to-Text) แบบ **Modern Dark Mode** พัฒนาด้วย **CustomTkinter** และประมวลผลด้วย **faster-whisper** โดยได้รับการปรับแต่งประสิทธิภาพให้เหมาะสมกับฮาร์ดแวร์เป้าหมายอย่าง **NVIDIA GeForce GTX 1660 Super (VRAM 6GB)**

---

## 🌟 ฟีเจอร์เด่น (Key Features)

1. **Modern Dark Mode UI**: ดีไซน์ทันสมัย เรียบหรู สะอาดตา ใช้งานง่ายด้วย CustomTkinter
2. **รองรับไฟล์หลากหลาย**: รองรับ `.mp3`, `.wav`, `.m4a`, `.mp4`, `.aac`, `.flac`, `.ogg`, `.wma`, `.mkv` พร้อมแสดงชื่อไฟล์, ขนาดไฟล์ และความยาวเสียง
3. **เสถียร ไม่ค้าง (Zero Freeze Architecture)**: 
   - แยก Worker Thread สำหรับประมวลผล AI ออกจาก Main GUI Thread อย่างสิ้นเชิง
   - หน้าต่างโปรแกรมยังคงลื่นไหล สามารถย้าย ย่อ ขยาย หรือกดปุ่มได้ตามปกติ แม้กำลังถอดไฟล์เสียงยาวถึง **5 ชั่วโมง**
4. **ออกแบบสำหรับ GTX 1660 Super (VRAM 6GB)**:
   - ใช้ `compute_type="float16"` บนสถาปัตยกรรม Turing ช่วยให้ประมวลผลได้รวดเร็วและใช้ VRAM ไม่เกินลิมิต 6GB
   - ตัวเลือกโมเดล: `tiny` (~1GB), `base` (~1.5GB), และ `small` (~2.5GB - ค่าเริ่มต้นแนะนำสำหรับภาษาไทย)
5. **⚡ โหมดความเร็วสูง (Turbo Mode)**:
   - ปรับเป็น Greedy Search (`beam_size=1`) และเปิดใช้งานการคำนวณ `int8_float16` บนชิป Turing ของ GTX 1660 Super
   - ช่วยลดระยะเวลาประมวลผลลงได้ถึง **2–3 เท่า** โดยที่ความแม่นยำภาษาไทยยังคงสูงมาก
6. **⏱️ กำหนดช่วงเวลาที่ต้องการถอด (Custom Time Range)**:
   - สามารถเลือกถอดเสียงเฉพาะช่วงที่ต้องการได้ เช่น `01:00:00` ถึง `02:30:00`
   - มีปุ่ม "ทั้งไฟล์" สำหรับรีเซ็ตกลับเป็นความยาวทั้งหมดได้อย่างรวดเร็ว
7. **Real-time Progress & ETA**:
   - แสดง Progress Bar (0 - 100%)
   - แสดงตำแหน่งเสียงปัจจุบันเทียบกับความยาวรวม (เช่น `01:15:30 / 03:00:00`)
   - แสดงเวลาที่ใช้ไป (Elapsed) และประมาณการเวลาที่เหลือ (ETA)
8. **Real-time Live Transcript & Auto-scroll**:
   - ข้อความที่ถอดได้จะปรากฏใน Text Box ทันทีทีละประโยค พร้อมเลื่อนหน้าจออัตโนมัติ
   - แสดง Timestamp รูปแบบ `[HH:MM:SS]`
9. **Real-time File Append**:
   - บันทึกข้อความลงไฟล์ `transcript.txt` ทันทีที่มีการพูดและทำ `flush()` ป้องกันข้อมูลสูญหายแม้ไฟดับหรือเครื่องดับกะทันหัน
10. **ปุ่มควบคุมครบครัน**:
    - ปุ่ม **เริ่มถอดเสียง** (Start)
    - ปุ่ม **หยุด** (Cancel - หยุดการทำงานทันที)
    - ปุ่ม **บันทึกไฟล์เป็น .txt** (Save As)
    - ปุ่ม **เปิดโฟลเดอร์ผลลัพธ์** (Open in Explorer)
    - ปุ่ม **คัดลอกข้อความ** (Copy to Clipboard)

## 🚀 ขั้นตอนการติดตั้ง (Installation)

### วิธีที่ 1: ติดตั้งผ่านสคริปต์คลิกเดียว (แนะนำ)
1. ดับเบิลคลิกที่ไฟล์ **`install.bat`**
2. รอให้ระบบดาวน์โหลดและติดตั้งไลบรารีจนเสร็จสิ้น
3. เมื่อขึ้นข้อความ "ติดตั้งเสร็จสมบูรณ์เรียบร้อยแล้ว!" ให้กดปุ่มใดก็ได้เพื่อปิดหน้าต่าง

### วิธีที่ 2: ติดตั้งด้วยตนเองผ่าน Terminal / PowerShell
เปิด PowerShell หรือ Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วพิมพ์คำสั่ง:

```bash
# 1. อัปเดต pip
python -m pip install --upgrade pip

# 2. ติดตั้งไลบรารีหลัก
pip install customtkinter faster-whisper av

# 3. ติดตั้งชุด DLL ของ CUDA 12 และ cuDNN สำหรับ Windows (จำเป็นสำหรับการรันบน GPU)
pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
```

## 💡 คำแนะนำสำหรับการตั้งค่าและการใช้งาน

1. **การเลือกขนาดโมเดล (Model Size)**:
   - **`small` (แนะนำ)**: แม่นยำสูง เหมาะสำหรับการถอดเสียงภาษาไทยในที่ประชุม ใช้ VRAM ประมาณ 2–2.5 GB บนการ์ดจอ GTX 1660 Super
   - **`base`**: ประมวลผลเร็วกว่า ใช้ VRAM น้อยกว่า เหมาะสำหรับไฟล์ที่เสียงพูดชัดเจน
   - **`tiny`**: เร็วที่สุด ใช้ VRAM น้อยที่สุด เหมาะสำหรับการทดสอบเบื้องต้น
2. **การเลือกอุปกรณ์ (Device)**:
   - **`CUDA (GPU)`**: ประมวลผลเร็วที่สุด แนะนำสำหรับเครื่องที่มี GTX 1660 Super
   - **`CPU`**: ใช้ประมวลผลเมื่อไม่ได้ใช้งาน GPU หรือต้องการสลับไปใช้พลัง CPU แทน
3. **การเลือกภาษา (Language)**:
   - **`ไทย (Thai)`**: แนะนำเลือกตัวเลือกนี้โดยตรงสำหรับการประชุมภาษาไทย จะช่วยให้โมเดลไม่สับสนกับเสียงดนตรีเปิดหัวหรือเสียงรบกวนในไฟล์
   - **`Auto Detect`**: เหมาะสำหรับกรณีที่มีการพูดสลับภาษาหลายภาษา

## 🔧 การแก้ไขปัญหาที่พบบ่อย (Troubleshooting)

### ปัญหา 1: ไม่พบ CUDA DLL หรือแจ้งเตือน CuDNN Error บน Windows
- เกิดจาก CTranslate2 บน Windows หาไฟล์ `cublas64_12.dll` หรือ `cudnn_ops_infer64_8.dll` ไม่เจอ
- **วิธีแก้**: ในโปรแกรมของเรามีฟังก์ชัน `setup_cuda_dll_paths()` ที่จะค้นหา DLL จากแพ็กเกจ `nvidia-cublas-cu12` และ `nvidia-cudnn-cu12` ให้อัตโนมัติ เพียงรันคำสั่ง:
  ```bash
  pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
  ```
- หรือสามารถเปลี่ยนตัวเลือก Device เป็น **`CPU`** เพื่อใช้งานต่อได้ทันที

### ปัญหา 2: การดาวน์โหลดโมเดลในครั้งแรก
- ในการรันแต่ละโมเดล (เช่น small, base) ครั้งแรก ระบบจะดาวน์โหลด Weights ของโมเดลจาก Hugging Face เก็บไว้ในเครื่องอัตโนมัติ ซึ่งจะใช้เวลาสักครู่ตามความเร็วอินเทอร์เน็ต และในครั้งถัดไปจะโหลดจากแคชในเครื่องทันที
